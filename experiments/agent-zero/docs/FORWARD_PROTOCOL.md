# Forward proving protocol — agent0-forward/1

**No genuine investment edge has been measured.** This version records the process and tests hypothetical arithmetic. It does not ingest real market outcomes or evaluate live balances. Before an authentic trial, independently approve source rights, acquisition, execution assumptions, private timestamped commitments and a fixed analysis plan.

## Preregister before outcomes

Define the observable universe and admission rule before discovery; preserve all admitted mints, including waits, rejects, failures, missing prices and later untradeable assets. The existing seven-token allowlist is convenience sampling, not an emerging-token population. Never infer birth time from first local capture. Report selection bias and missing-provider intervals.

Each decision stores its original server time, exact mint, every evidence hash then available, full qualification criteria/version, current policy hash, hypothesis, disqualifiers, missing evidence, entry/invalidation conditions and liquidity/cost considerations. Original capture and local availability clocks differ. A later historical import is available **later** and cannot alter that decision. A new thesis or rule is a new append, never an overwrite.

Priority is provisional evidence readiness, not predictive conviction. Proposed future ordering: resolve disqualifying risks first; establish size-aware tradability/costs next; compare preregistered sustained observations last. Unsupported concentration, relationships, manipulation and exit dimensions stay NOT OBSERVED. An absent mint authority is not an opportunity signal. Current input cannot justify a token ranking or ELIGIBLE state.

## Minimum paper execution rules

The demonstration validator requires exact token/pool/quote identity and original decimals; canonical unsigned integer strings (u64 inputs, BigInt arithmetic); known pair source clocks; source lag ≤300 seconds; ≥3 aligned samples; and a preregistered maximum gap. These are **mechanics thresholds, not a statistically sufficient trading study**. No market-return adapter is authorized.

Preregister quantity, quote budget, entry latency, maximum quote wait, holding horizon, maximum sample gap, all-in fees and adverse slippage. Use the first timely post-decision quote after latency, never the cheapest retrospective entry. Exit at the first timely quote after the fixed horizon. Do not optimize a stop/exit after seeing an outcome. Reject identity/clock conflicts, budget excess, insufficient depth or exit capacity. Later price history cannot certify an executable fill.

Costs are rounded against the paper trader: entry cost upward, exit proceeds downward; fees both ways. SOL network costs, routing, priority fees, transfer fees and quote/USD conversions need independent evidence before real modeling. A missing/untradeable exit is **unpriced**, not a zero return or an invented −100% realization. Keep it in the denominator and report a separately labeled full-loss stress scenario only if implemented later. Negative manual net units stay incomplete-history claims; no clamp to zero or implied profit.

Sample MAE/MFE are minimum/maximum observed price relative to entry, before fees; sampled drawdown is peak-to-subsequent-trough. Sampled peak is not true ATH. Net return uses fee/slippage-adjusted outlay/proceeds in one exact quote unit, never an unsupported USD conversion. The v1 implementation computes these only for labeled fictional observations. Genuine fund drawdown, capital actually at risk, realized/unrealized return, NAV and exposure are unavailable; $10 is a proposed ceiling, not an actual risk amount.

## Benchmarks, bias and stopping

Freeze three comparisons before acquiring outcomes: SOL in the same quote/window after costs; an equal-notional cohort of every then-eligible mint without survivor substitution; and a simple fixed-horizon first-qualifying-quote rule with identical clocks/cost gates. No genuine benchmark data is currently integrated. Rejected candidates need approved outcome observations too, so false negatives do not disappear.

Run an initial 30-calendar-day **process audit**, without a minimum trade count. Publish neither alpha nor a win rate from this period by default. Report admissions, decisions, rejections, priced/unpriced/dead assets, duplicate/conflicting records, coverage, maximum modeled exposure, costs and missing benchmarks. Report the strategy version and every rule change. Preserve rejected, losing and censored observations. Compare net strategy/baseline differences with uncertainty, dependence and multiple testing accounted for; define statistical power before any claim. A small chosen sample or isolated moonshot cannot establish edge.

Stop outcome scoring on clock/identity conflict, unknown rights, coverage failure or missing exit. Stop any future capital trial after a policy breach/loss/failed exit until separate founder review. Do not remove unfavorable samples or silently substitute a benchmark. A different strategy starts a new forward cohort; no retrospective tuning of the original result.

Local SHA-256 chains detect accidental changes and app-level overwrites; an owner can rewrite the whole file. Independent timestamped pre-outcome anchors and controlled backups are required to make the forward record defensible. No signed/durable/externally witnessed receipt is claimed.
